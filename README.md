**Kopi Senja Lane** — a spot-the-difference game set on one invented Indonesian street, in three scenes: a café at dusk, a night market, and a rainy morning. Two near-identical pictures side by side, 7–9 differences per level, golden rings mark what you find, a countdown keeps the pressure on, and hints cost points. All art is original SVG drawn in code; all sounds are synthesized in the browser. No network requests, no libraries — just static files that open in desktop Chrome and play.

## Run it

```sh
cd game && python3 -m http.server 8080
# then open http://localhost:8080 in desktop Chrome
```

Click a difference on either picture to mark it. `H` for a hint, `R` to restart the level. Wrong clicks cost 25 points; every find is worth 100, plus a time bonus when a level is cleared.
